# Foto

**Uncensored. Offline. Unlimited.**

Foto is an offline AI image generator built for users who want complete creative freedom. Generate unlimited images locally without subscriptions, internet access, cloud processing, or built-in content restrictions.

## Features

* Generate unlimited AI images
* Uncensored image generation
* Runs completely offline
* 100% local processing for maximum privacy
* Fast generation powered by your hardware
* High-quality image output
* No accounts, no API keys, no subscriptions
* Simple and lightweight interface

## Why Foto?

Most AI image generators rely on cloud services, usage limits, and content filtering. Foto is different.

* Your prompts never leave your device.
* Your generated images belong to you.
* No monthly fees.
* No internet required.
* No artificial generation limits.
* No built-in censorship.

You control the models. You control the output.

## Privacy

Foto performs all image generation locally on your computer.

* No cloud processing
* No data collection
* No prompt logging
* No telemetry
* No account required

Everything stays on your device.

## Requirements

* macOS
* GPU recommended for faster generation
* Sufficient RAM/VRAM depending on the model

## Installation

1. Download the latest release.
2. Install Foto.
3. Launch the application.
4. Load your preferred AI model.
5. Start generating.
